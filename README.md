# BookStore Application

A comprehensive bookstore management system built with Spring Boot.

## Features

- User Authentication & Authorization
- Category Management
- Product Management
- Inquiry System
- Chat/Conversation System
- Notification System

## Technology Stack

- Java 17+
- Spring Boot
- Spring Security
- JWT Authentication
- JPA/Hibernate
- Maven
